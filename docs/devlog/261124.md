## BG-02 신고 실패와 재시도

신고 실패 안내를 신고 창 안에 표시한다. 사유가 유지되며 재시도가 성공했을 때만 접수 상태를 표시한다. 브라우저에서 첫 요청에 429를 적용하고 재시도는 실제 서버로 전송했다. 기존 백엔드 검사가 채팅 전송 한도, 공유 IP의 세션 발급, 중복 신고 및 만료를 담당한다.

격리 PostgreSQL에서 Spring 108개, Node 11개, Chromium 6개가 모두 통과했다. 테스트 신고를 운영자용 읽기 전용 SQL로 열람해 증거와 기한을 확인했다. 테스트 메시지는 운영 조치 없이 종료했다.

## BG-03 사내 카페 첫 화면

온기의 햇살과 기존 글꼴을 유지했다. 화면 높이에 따라 여백을 늘려 활동 선반을 하단에 두고, 분위기 설정은 그 아래에 배치했다. 선반 열기를 활동 내용 아래에 두고 고정 배치를 없앴다. 선반으로 돌아오면 직전에 고른 활동으로 키보드 초점이 돌아간다.

360px와 1280px에서 첫 방문과 활동 복귀, 키보드, 테마 변경을 확인했다. 방 목록 응답을 503과 빈 배열로 바꿔 채팅 외 활동이 열리는지 검증했다. 격리 PostgreSQL에서 Spring 108개, Node 11개, Chromium 8개가 통과했다.
