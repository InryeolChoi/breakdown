## Parent

관련 명세의 제목·링크. 부모가 없다면 이 섹션을 제거한다.

## What to build

사용자가 어디서 무엇을 하고 어떤 결과를 얻는지. UI/API/테스트 별 작업 목록보다 완성할 동작을 적는다.

## Acceptance criteria

- [ ] 정상 동작과 검증할 결과
- [ ] 실패 시 사용자에게 보일 동작
- [ ] 경계 상황과 검증할 결과

## Blocked by

실제 선행 이슈의 제목·링크 또는 없음. 게시 후 native blocking 관계도 연결한다.

## Testing boundary

테스트할 공개 사용자 경계, 통제할 외부 응답/데이터, 실제 연결 확인 방법.

## Out of scope

이번 기능에서 다루지 않는 범위.

## Open decisions

남은 결정 또는 없음. 답변이 필요한 상태에서는 ready-for-agent를 붙이지 않는다.
