# 사내 카페 첫 화면 구성안

2026-10-15 비교 초안. 사용자 선택 전이며 프런트 구현·정책 추가가 아니다.

## 최신 피드백

2026-10-16: 사용자가 원하는 움직임은 자리에 앉아 고개를 돌리는 느낌이다. 햇살은 등 뒤에서 들어오고, 직접 창을 보지 않아도 고층빌딩 안의 개방감을 원한다. 식물·보이는 업무공간은 제외하며 커피 머신·정수기·간식 상자가 있는 사내 카페 셀프바를 배경에 포함한다. 기계 조작·이동·간식 집기 기능은 합의한 범위가 아니다. 실제 3D 구현 기술은 아직 미정이다.

사용자는 아래 두 안을 게시판처럼 느껴져 선호하지 않는다고 했다. 창문을 그림으로 덧붙인 폼보다 실제 공간을 바라보는 느낌을 원한다. 따라서 아래 구성은 승인안이 아니며 비교 이력으로 남긴다. 다음 탐색은 카페 입구 시점의 창가·공용 테이블·주변 오피스를 중심에 두는 공간 이미지다. 주제를 눌러 같은 화면에 닉네임과 입장을 펼치는 방식은 검토할 제안이며 사용자 확정 사항은 아니다.

## 공통 방향

- 개방된 오피스 사이의 카페. 창문, 낮은 파티션, 긴 테이블로 공간감을 만든다. 컵·아바타·좌석 이동을 중심에 두지 않는다.
- 방 선택과 닉네임 선택 입력을 같은 화면에 둔다. 실제 입장 시 기존 HTTP 익명 사용자 준비 후 WebSocket 접속을 잇는다.
- 예시는 평일 10:30의 점심메뉴방 한 개다. 실제 운영 상태나 접속 인원을 나타내지 않는다. 닫힌 방 목록·다음 개장 정보는 기존 API에 없으므로 임의로 제품 계약에 추가하지 않는다.
- 글은 왼쪽 정렬. 제목·본문 모두 Apple SD Gothic Neo / 맑은 고딕 / sans-serif의 시스템 한글 글꼴을 쓰고 제목은 중간 굵기로 한다.
- 밝은 팔레트 후보: 채광 #E5F0F4, 벽 #F7F9F8, 잎 #315D4C, 글 #233934, 목재 #B28E68, 유리틀 #BCCBC8. 어두운 테마에서도 명암 역할을 유지한다.

## 창가 라운지

가로로 긴 창과 오피스 풍경 아래에 입장 영역을 둔다. 처음 방문했을 때 공간의 인상이 먼저 남는다.

```text
브랜드                       로그인 없이 잠깐
┌────────── 큰 창 / 사내 카페 풍경 ────────────┐
│                  잠깐, 쉬었다 가요          │
└───────────────────────────────────────────┘
열린 방 선택              닉네임 (선택)
[점심메뉴방 10:00~11:30]   [                  ]
                          [선택한 방에 입장]
```

모바일은 낮은 높이의 풍경, 방 선택, 닉네임, 입장 순으로 한 화면 흐름에 배치한다. 창 장면 때문에 입력이 아래로 너무 밀리지 않게 한다.

## 오피스 사이 카페

왼쪽에는 창가 테이블과 오피스 파티션, 오른쪽에는 방 선택과 닉네임을 모은 입장 패널을 둔다. 이용할 행동이 더 빨리 보인다.

```text
브랜드                       로그인 없이 잠깐
┌──────────────────┬────────────────────────┐
│ 창문 / 테이블     │ 지금, 잠깐 쉴까요       │
│ 오피스 파티션     │ 열린 방 선택            │
│                  │ [점심메뉴방]            │
│                  │ 닉네임 (선택) [       ] │
│                  │ [선택한 방에 입장]      │
└──────────────────┴────────────────────────┘
```

모바일은 풍경을 작은 상단 띠로 줄이고 입장 패널을 본문으로 둔다. 두 안 모두 필수 행동은 스크롤·장식보다 우선한다.

## 상태와 검토

- 정상: 방을 고르고 닉네임을 입력하거나 비운 채 입장. 시안에서는 실제 가입·접속 없이 선택 결과만 확인한다.
- 빈 상태: 열린 방 없음과 비활성 입장. 운영 시간 안내는 별도 서버 계약 확인 후 정할 후보이며 시안에는 다음 개장 시각을 만들지 않는다.
- 실패: 목록을 불러오지 못했다는 안내와 다시 시도. 빈 목록으로 위장하지 않는다.
- 공통: 닉네임 30자 정책은 서버가 최종 판단한다. 재방문 표시 방식은 미정이라 이번 시안은 신규 방문 예시다.
- 일반적인 랜딩 페이지처럼 큰 홍보 문구와 반복 카드를 넣지 않고, 기억할 요소는 창가 풍경 하나로 제한했다. 방 선택을 실제 좌석 선택처럼 보이게 하는 안은 이동형 메타버스 오해가 생겨 제외했다.
- 추천은 오피스 사이 카페. 첫 화면에서 방과 닉네임이 함께 보이고 모바일에서도 입장 흐름을 짧게 유지한다. 사용자의 선택은 아직 받지 않았다.
