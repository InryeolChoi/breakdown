# 입장 전과 채팅 중 화면 — 디자인 검토안

2026-11-04. 공간 기준은 기존 승인 이미지를 유지한다. 아래 UI 배치는 AI 제안이며 아직 승인 전이다. 실제 프런트 구현이나 새로운 서버 정책이 아니다.

## 공통 디자인 계획

- 기억할 요소는 탁자에 앉은 공간감이다. 햇살은 등 뒤, 왼쪽 깊은 공간은 막힌 벽, 오른쪽은 커피 머신·정수기·간식 상자다. 식물·업무공간·아바타·좌석 이동은 넣지 않는다.
- 색상 역할: 햇빛 벽 #F5EFE6, 목재 #B68C62, 입력면 #FFFEFB, 본문 #263B33, 강조 #315C4C, 구분선 #D6CEC1. 공간 기준을 따르는 색이며 일반적인 카드형 랜딩 페이지를 만들기 위한 장식 팔레트가 아니다.
- 제목과 본문은 시스템 한글 sans-serif 계열. 본문은 왼쪽 정렬하고, 핵심 버튼은 정확한 행동을 적는다.
- 사용자의 시선을 계속 움직이게 하지 않는다. 움직임 자체는 이번 정지 이미지로 검증할 수 없다. 채팅 중 고정 여부·조작 범위는 후속 디자인 과제다.

## 입장 전

방 선택과 닉네임을 탁자 영역의 작은 안내면 하나에 함께 둔다. 별도 대형 중앙 모달이나 좌석 선택 화면은 없다. 신규 방문 예시이며 기존 사용자 닉네임 변경 기능을 약속하지 않는다.

```text
브랜드                 카페 공간
          탁자 / 맞은편 의자
      ┌──────── 작은 입장 안내 ────────┐
      │ 방 선택: 점심메뉴방            │
      │ 닉네임(선택) [               ] │
      │ 비우면 서버 자동 생성          │
      │ [점심메뉴방에 입장]            │
      └───────────────────────────────┘
```

## 채팅 중

같은 공간과 같은 탁자 영역에 대화면을 둔다. 고정된 읽기 영역에서 닉네임·본문·시각을 읽고 입력·전송한다. 셀프바 전체를 가리는 화면 높이는 피한다. 신고는 다른 사용자의 메시지에 연결하고, 공간 사물에 기능을 억지로 붙이지 않는다.

```text
브랜드                 카페 공간
          탁자 / 맞은편 의자
      ┌──────── 대화면 ───────────────┐
      │ 점심메뉴방           [나가기] │
      │ 닉네임 / 본문 / 시각 / 신고   │
      │ 내 닉네임 / 본문 / 시각       │
      │ [메시지 입력            ][전송]│
      └──────────────────────────────┘
```

## 검토와 한계

거대한 폼과 반복 카드를 만드는 대신 같은 탁자 영역에서 입장 안내가 대화면으로 바뀌는 구성을 제안한다. 공간에 글자를 원근으로 박아 읽기 어렵게 만들지 않고 UI는 정면으로 읽히게 한다. 이미지 예시는 평일 10:30, 점심메뉴방 하나이며 수신 대화는 시안용 문구다. 실제 참가자 수·과거 대화 조회·다음 방 개장 계약을 추가하지 않는다.

이번에는 데스크톱 두 상태를 비교한다. 모바일, 열린 방 없음·오류·운영 종료·신고 결과 등 상태는 다음 디자인 검토이며 빠뜨린 채 구현 완료로 주장하지 않는다. 이미지 속 글자·행 수·색상은 구현 확정값이 아니다.

자체 검토: 공간과 셀프바가 잘 보이고 입장·대화 영역이 같은 위치로 이어진다. 다만 채팅은 표처럼 정렬되어 게시판 인상을 줄 수 있고, 입장 안내도 아직 일반적인 흰 폼으로 보인다. 생성 이미지의 일부 한글은 부정확해 최종 문구 검수 대상이다. 사용자가 이미 좋아한다고 한 공간 배경의 승인과 UI 배치 승인은 구분한다. 실제 고개 회전·키보드·모바일 가독성은 이 정지 이미지로 검증하지 않았다.
