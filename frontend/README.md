# Breakground 프런트 프로토타입

2026-11-06 사용자 선택으로 미니멀 방향에 집중한다. 배포 구조와 기본 테마 저장 정책은 미정이다. 현재 진입은 `/minimal`을 사용한다.

- `/spatial`: 중단한 공간형 비교 시안. 과거 비교용 라우트로만 남아 있다.
- `/minimal`: 빙하·온기·대나무숲·블랙 네 가지 분위기를 바꿔보는 미니멀 화면. UI와 대화 상태는 유지하고 배경·글자·선·강조 색을 함께 바꾼다. 초기값은 비교용 빙하이며 선택을 저장하지 않는다.
- `/`: 비교 시작 화면. 기존 `/retro` 주소는 `/minimal`로 이동한다.

## 실행

저장소 루트에서 `make`, `./gradlew bootRun --args='--server.address=127.0.0.1'`으로 기존 서버를 실행한다. 다른 터미널에서 이 디렉터리로 이동해 다음을 실행한다.

```sh
npm ci
npm run dev
```

브라우저는 `http://127.0.0.1:3000/minimal`로 접속한다. 포트는 `PORT`, API 대상은 `BACKEND_URL`로 바꿀 수 있다. 기본 대상은 `http://127.0.0.1:8080`이며 프런트 서버는 loopback에만 바인딩한다.

## 체험과 실제 연결

처음은 **체험 모드**다. 자동 답변은 예시이며 사용자·메시지·신고를 DB에 저장하지 않는다. 실제 사용자와 채팅하는 것처럼 표시하지 않는다. 실제 서버로 바꾸기를 누르면 현재 열린 방을 조회하고, 입장 시 익명 사용자 HTTP API에서 HttpOnly 쿠키를 준비한 뒤 WebSocket으로 연결한다.

실제 모드의 방 운영 시간은 기존 서버 정책을 따른다. 열린 방이 없으면 실제 입장은 할 수 없고, 그 상태를 명확히 표시하며 체험 모드를 안내한다. 쿠키를 JS/localStorage에 저장하지 않는다. 재방문 닉네임은 기존 서버 정책대로 유지한다. 동일 브라우저 탭들은 같은 익명 쿠키를 공유한다. 서로 다른 사용자로 비교하려면 다른 브라우저 또는 시크릿 창을 쓴다.

HTTP `/api/*`와 `/ws/rooms/*`는 Node 개발 게이트웨이를 통해 Spring으로 전달한다. Host·Origin을 함께 유지해 브라우저와 Spring 사이에 동일 출처 조건을 만든다. Spring의 WebSocket 허용 출처를 wildcard로 바꾸지 않는다. Next rewrite만으로 WS 중계를 가정하지 않았다. 이 custom server는 로컬 검증용이며 운영 프록시·HTTPS 구조를 확정하지 않는다.

## 검증

```sh
npm test
npm run typecheck
npm run build
RUN_LIVE_TESTS=1 node --test tests/live.test.mjs
```

실제 연동 테스트는 현재 열린 기존 방이 있어야 한다. 별도 익명 사용자와 메시지, 테스트 신고를 로컬 DB에 생성한다. 컨테이너 볼륨이나 기존 기록을 삭제하지 않는다. 저장·쿠키·Origin·두 연결 수신·입력 오류 후 연결 유지·신고와 중복 신고를 확인한다. 개발 중인 서버에서 production build를 동시에 반복 실행하지 않는 편이 좋다.

사용자 메시지는 서버가 전달한 후 표시한다. `send()` 호출만으로 성공 표시하지 않으며 자동 재전송하지 않는다. 메시지 목록은 최대 200개 표시, 화면을 떠나면 연결을 닫고 대화를 복원하지 않는다. 이 200개는 브라우저 표시 버퍼로 서버 메시지 정책을 바꾸는 것이 아니다.

공간형 비교는 종료 방향이다. 미니멀은 네 가지 테마를 화면 하단에서 전환하며 같은 방·메시지·작성 중인 입력을 유지한다. 모든 글씨는 600 굵기로 맞췄다. 입장 후에는 소개 제목을 접고 대화 목록을 넓히며, 목록 스크롤과 입력창을 분리한다. 냉기는 먼 구름 7초·가까운 구름 4.8초가 오른쪽 위에서 왼쪽 아래로 흐른다. 멈춤 버튼과 reduced-motion 정지를 지원한다. 모바일 화면은 별도로 확인하며 검증 결과는 devlog에 남긴다. 서버의 익명 사용자·신고 증거 정책은 바꾸지 않았다.

## 이미지

`public/images/cafe-spatial.png`는 승인한 카페 구도를 유지하고 UI를 제거하도록 기본 이미지 생성 도구로 만든 배경이다. 기존 승인 이미지는 덮어쓰지 않았다. 레트로 픽셀 배경 실험은 사용자가 원하는 비교 기준과 달라 현재 화면에서 사용하지 않는다.

`public/images/cafe-panorama.png`는 중단한 파노라마 실험 자산으로 현재 화면에서는 사용하지 않는다. 생성된 이미지는 검증된 360도 촬영물이 아니다. 현재 공간형은 cafe-spatial.png만 사용한다.
