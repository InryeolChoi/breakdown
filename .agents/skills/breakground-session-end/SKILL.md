# Breakground 세션 종료

사용자가 작업 종료 의사를 표현하면, 현재 대화에서 논의한 내용을 빠뜨리지 않고 다음을 수행한다.

1. 시스템의 현재 날짜에 해당하는 `docs/devlog/YYMMDD.md`에 질문·답변·설계 결정·검증 결과와 다음 시작 지점을 정리해 그날의 기록을 마무리한다. 파일이 없으면 새로 만든다.
2. 프로젝트 루트에서 `make fclean`을 실행한다. 이 명령은 PostgreSQL 컨테이너와 네트워크를 내린 뒤 Docker Desktop 종료를 시도한다. 실패하면 실제 실패 지점과 원인을 사용자에게 알린다.
3. 작업 트리의 변경 사항을 확인하고 공백 오류를 검사한다. 비밀값이나 빌드 산출물을 포함하지 않는지 확인한 뒤, 이번 작업의 변경 사항을 커밋하고 현재 브랜치를 GitHub 원격 저장소에 푸시한다.

종료 요청은 이 프로젝트에서 위 세 가지 마무리 작업의 권한을 포함한다. 다만 `make fclean`이 실패했을 때 임의로 강제 종료하거나 데이터를 삭제하는 명령을 추가로 실행하지 않는다.
